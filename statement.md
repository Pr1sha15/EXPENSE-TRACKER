# Problem Statement

## Problem

Students often find it difficult to keep track of their daily expenses and manage their monthly spending. A simple system is needed to record and monitor expenses efficiently.

## Scope of the Project

The project provides a basic expense management system using Python and SQLite. It allows users to record, view, edit, and delete expenses, analyse spending by category, and monitor their monthly budget.

## Target Users

The primary users are students who want to keep track of their personal and daily expenses.

## High-Level Features

* Add and store expenses
* View recorded expenses
* Edit and delete expenses
* Calculate total spending
* Analyse spending by category
* Set and check a monthly budget
* Display budget warnings when spending is high
* Store expense data using SQLite
